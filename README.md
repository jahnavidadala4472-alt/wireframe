# wireframe
The Mobile App Wireframing process focuses on creating the basic structure and layout of a mobile application before adding colors, animations, or final visuals. It helps designers plan how the app will work and how users will interact with it.

Description

This activity involves designing low-fidelity wireframes, which are simple sketches or digital layouts that represent the screens of a mobile app. These wireframes help visualize the app’s navigation, features, and user experience in the early stages of development.

Key Features Explained
Conduct basic user research
Understand the target users, their needs, problems, and expectations before designing the app.
Create user personas and user flows
Build fictional user profiles and map out how users move through the app to complete tasks.
Design low-fidelity wireframes using Figma or Adobe XD
Use design tools to create simple layouts showing buttons, menus, and screen structure without detailed styling.
Document the design thinking process
Record ideas, decisions, and problem-solving steps followed during the design process.
Expected Outcome

By completing this task, learners gain an understanding of:

Early-stage mobile app planning
User-centered design thinking
App screen organization and navigation
Creating effective user flows and wireframes for future UI development
